## 使用方式

1. 选择对应角色的 skill 文件。
2. 复制内容到 AI 对话中。
3. 在最后的 `【我的具体任务或项目资料】` 中填入真实任务、分析对象、边界、工况、数据和约束。
4. 如需多人协作，必须先明确牵头人、职责边界、输入输出和批准主体。
