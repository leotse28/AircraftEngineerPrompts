# AircraftEngineerPrompts

这是一个面向飞机与系统工程领域的 Prompt 集合，汇总了 26 个角色/专业工程师的完整 Prompt，用于在 AI 助手中复用和协同分析。

本仓库同时保留了两种形式：

- `Prompts/`：原始可直接复制的 TXT Prompt 文件
- `skills/`：按“角色 skill”整理后的可重复调用版本，适合 AI 工具/编码助手/代理场景使用

## 项目简介

该项目覆盖了飞机总体设计、系统工程、接口集成、需求管理、安全性与可靠性、适航审定、项目管理、试验验证以及 ATA 章节专项设计等典型工程角色。

目标是帮助工程师、架构师、系统工程师和交付人员，把关键设计问题、职责边界、评审要求和验证方法，结构化为可直接交给 AI 使用的 prompts。

## 使用方式

### 1. 直接复制 Prompt

进入 `Prompts/` 目录，选择对应角色的 TXT 文件，复制全文后贴给 AI。

### 2. 使用统一 skill 版本

进入 `skills/` 目录，选择对应角色 `.md` 文件，用于更适合工具/代理协作的场景。

### 3. 填写真实任务信息

在最后的“我的具体任务或项目资料”处，填写以下内容：

- 任务目标
- 设计对象和边界
- 工况和环境条件
- 已有要求/标准/设计阈值
- 真实数据、证据和约束

### 4. 协作时明确职责边界

如果多个角色协作，需要提前明确：

- 牵头方
- 职责边界
- 输入输出
- 审批主体
- 版本管理和配置控制

## 设计哲学

本项目并不试图替代真实工程标准、审批流程、适航审定或设计责任。它的作用是：

- 提供工程角色的结构化思考框架
-强化需求、接口、风险、验证和证据意识
- 提高 AI 对飞机系统工程任务的上下文表达能力
- 帮助工程人员快速组织分析和评审输出

## 重要说明

- 本仓库中的 Prompt 仅用于结构化分析与协同辅助，不代表模型具备工程批准、签字、适航或技术认证权限。
- 所有关键标准、设计阈值、批准结论和验证结果，必须基于真实项目资料、要求和正式依据。
- 若用于实际工程任务，请结合项目管理流程、配置管理、风险管理和验证活动。
