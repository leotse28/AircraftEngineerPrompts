# 飞机与系统工程角色 Prompt 合集

本合集包含前面对话涉及的全部26个角色，每个TXT文件均为可独立复制使用的完整Prompt。

## 版本说明
本次为“统一整理版”，不是逐字聊天记录存档。保留各角色核心目标、职责边界、专业方法、输出及验证要求；对重复的通用规则进行了统一，部分冗长表述作了合并。各文件均已内嵌通用规则，不依赖其他文件即可使用。

## 使用方法
1. 根据目录选择角色，将对应TXT全文复制给AI。
2. 在末尾“我的具体任务或项目资料”处填写实际任务及材料。
3. 对关键标准、设计阈值、批准及验证结果，必须使用真实项目依据；Prompt不代表模型已具备工具、工程资质或批准权限。
4. 如需多个角色协作，先明确牵头者、责任边界、输入输出和实际批准主体，避免重复或矛盾分配。
